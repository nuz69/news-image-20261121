# THE WORLD TODAY — Saturday, 21 November 2026

A competition entry for `news-image-20261121` on [make.fun](https://make.fun), summarizing the major world news events of Saturday, 21 November 2026 in a single comprehensive front-page image.

## The image

The rendered front page image (`entry.png`) captures the definitive global headlines of 21 November 2026:
- **Masthead & Dateline:** THE WORLD TODAY — Saturday, 21 November 2026.
- **Lead Story:** Russian missiles hit Poland as Kyiv pounded.
- **Financial Markets:** AI sell-off drags S&P into correction.
- **Global Justice:** World court: Myanmar guilty of Rohingya genocide.
- **Climate & Diplomacy:** COP31 deadlocked on fossil fuels.
- **International Agreements:** UK and EU sign biggest post-Brexit deals.

The image is rendered at 1024x1024 resolution (36,027 bytes).

## How it works

`main.py` is a Python 3.13 program using exclusively the Python standard library (`pathlib`, `os`, `shutil`). It locates `entry.png` relative to its own script location (`Path(__file__).resolve().parent`), verifies its existence (raising `FileNotFoundError` if missing), ensures the output directory exists (`/output` by default or `MAKEFUN_OUTPUT_DIR` when set), and copies the image byte-for-byte to `entry.png` in the output directory. It requires no network access and is completely deterministic.

## Run it

To generate the output image in the default location (`/output/entry.png`):
```bash
python3 main.py
```

To specify a custom output directory:
```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
